# Nikhil Jagirdar Portfolio — Version 5

Premium executive / consulting-style static portfolio.

## What changed in Version 5
- Expanded consulting-style case studies with clickable full-screen detail views.
- Each case separates Business Question, Analytical Approach, Work Performed, Business Context and documented Impact.
- Added a stronger visual career timeline so Experience is easier to scan.
- Recent analytics roles remain the primary story; earlier India engineering experience is separated as supporting context.
- No framework, build process, database or npm setup required.

## Easy editing
1. Open `index.html` in VS Code, Cursor, Notepad++, or another editor.
2. Search for `case` or the visible text you want to change.
3. Case-study details are stored in the `const cases = {...}` JavaScript object near the bottom of the file.
4. Replace `nikhil-hero.png` to change the portrait. Keep the same filename.
5. Change colors in the `:root` section near the top of the CSS.
6. Replace the résumé file if you want a newer version, keeping the filename or updating the résumé link.

## Publish
This is a static website. It can be published using GitHub Pages, Netlify, Vercel, Cloudflare Pages, or ordinary web hosting.
